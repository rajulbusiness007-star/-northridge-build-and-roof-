## 🛠️ Architecture & Tech Stack

- **Frontend Core**: React 19 (SPA Architecture) with TypeScript
- **Styling & Design System**: Tailwind CSS v4 (`@tailwindcss/vite`) with curated dark navy (`#0d1b2a`), slate (`#16222f`), and terracotta orange (`#e05d26`) tokens
- **Fullstack Runtime**: Express 4 API server integrated directly with Vite middleware in development and static bundle serving in production
- **Icons & Motion**: Lucide React + `motion` physics animations
- **Local Dev Server**: Tested and verified on `http://localhost:3000`

## 💻 Local Setup & Development

```bash
# 1. Clone repository
git clone https://github.com/rajulbusiness007-star/-northridge-build-and-roof-.git
cd -northridge-build-and-roof-

# 2. Install dependencies
npm install --legacy-peer-deps

# 3. Start development server
npm run dev
# The website will be live on http://localhost:3000
```
